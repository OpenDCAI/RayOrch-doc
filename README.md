# RayOrch Documentation

Official bilingual documentation for [RayOrch](https://github.com/OpenDCAI/RayOrch), built with VuePress 2 and VuePress Theme Plume.

## Local development

```bash
npm ci
npm run docs:dev
```

Build before opening a pull request:

```bash
npm run docs:build
```

English pages live in `docs/en/`; Chinese pages live in `docs/zh/`. Keep their navigation and subject coverage aligned. The site is configured for GitHub Pages at `/RayOrch-Doc/`.
